# GameDesign Fall 2026 Project 2 Clicker Game

# Artistic Statement 

*I wanted to create a relaxing clicker game where players feel calm when playing. I chose to have a gray, black, blue color palate to portray cool colors for a calming feeling, but I also wanted to include elements from Japan like samurai to make it look cool.*

**Assets For each element of the game**

- blue calm background art
- samurai icon for button (fit the color scheme)
- coin for game juice
- coin music for game juice
- generator icon of a samurai
- calming music playing the entire game (did not implement this yet due to time contsraints)
